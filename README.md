# Все, что я узнал o Git:
* cd - переход
* pwd - показать, где я нахожусь
* ls - показать, что тут находиться
* touch - создает файл
* mkdir - создает путь(-m - расширяет его)
* cp - копируем и куда копируем
* cat - читать текстовый документ
* rm - удаляет файл
* rmdir - удаляет путь
* с && можно воыполнить несколько команд
* tab - не только дописывает файлы и пути, но и команды
* с git config --global user.name и git config --global user.email указываем ФИО и электронную почту
* git init - создаем репозиторий
* git status - проверка состояния репозитория
* dit add - подготовка файлов к репозиторий
* git commit -m - добавляем файлы в репозиторий
* git log - история коммитов
* ssh-keygen -t ed25519 -C - генерирует SHH-ключ
* clip < ~/.ssh/id_ed25519.pub - копирует содержимое ключа в буфер обмена
* ssh -T git@github.com - проверяем правильность ключа
* git remote add - привязка локального и удаленного репозитория
* git remote -v - убедиться, что репозитории связаны
* git push -m - отправить изменения на удаленный репозиторий
* git clone - клонироуем репозиторий
